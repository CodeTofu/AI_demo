# 基金持仓 FAQ（RAG 演示语料）

## 持仓收益怎么计算

在本演示应用中，**持仓收益（profitLoss）** 指用户录入的盈亏金额（元），可与截图或 App 列表中的「持仓收益」「盈亏」字段对应。

**当前市值**（currentValue）为录入的持仓金额。系统根据基金代码拉取实时净值，用于展示与组合分析；收益金额以用户记录为准，若仅有收益率而无金额，可暂填 0 并在对话中说明。

## 成本与份额

持仓表保存 **总成本 costTotal** 与 **成本单价 costPrice**，不直接保存份额。份额可按公式推算：份额 ≈ costTotal / costPrice。

## 记录持仓

同一用户对同一只基金（6 位代码）重复记录时，会 **更新** 原有记录，不会重复新增多条。

## 查看组合

查看总持仓、总盈亏、明细时，应以 **analyzePortfolio** 工具返回的数据库结果为准，不要编造持仓列表。

## 删除持仓

支持按基金代码删除单条持仓，也支持 **清空全部持仓**（clearAllHoldings）。
